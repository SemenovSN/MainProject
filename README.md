## Инструкция по установке и использованию
Клонируйте репозиторий:
```bash
git clone https://github.com/SemenovSN/MainProject.git
cd MainProject
```
Импортируйте необходимые функции в свой Python-скрипт:
```python
from src.masks import get_mask_card_number, get_mask_account
from src.widget import mask_account_card, get_date
from src.processing import filter_by_state, sort_by_date
```
## Примеры использования
Функция __get_mask_card_number__  
Принимает номер карты в качестве аргумента. Возвращает маску номера карты:
```
Visa Platinum 1234567890123456 -> Visa Platinum 1234 56** **** 3456
```
Функция __get_mask_account__  
Принимает номер счета в качестве аргумента. Возвращает маску номера счета.  
```
Счет 12345678901234567890 -> Счет **7890
```
Функция __mask_account_card__
Принимает один аргумент — строку, содержащую тип и номер карты или счета. Возвращает строку с замаскированным номером.  
<u>Используемые функции:</u> get_mask_card_number, get_mask_account
```
Visa Platinum 1234567890123456 -> Visa Platinum 1234 56** **** 3456
Счет 12345678901234567890 -> Счет **7890
```
Функция __get_date__  
Принимает на вход строку с датой в формате ISO 8601. Возвращает строку в формате "ДД.ММ.ГГГГ"
```
2024-03-11T02:26:18.671407 -> 11.03.2024
```
Функция __get_date__  
Принимает на вход строку с датой в формате ISO 8601. Возвращает строку в формате "ДД.ММ.ГГГГ"
```
2024-03-11T02:26:18.671407 -> 11.03.2024
```
Функция __filter_by_state__  
Принимает список словарей и опционально значение для ключа state (по умолчанию 'EXECUTED').
Возвращает новый список словарей, содержащий только те словари, у которых ключ state соответствует указанному значению.
```
2024-03-11T02:26:18.671407 -> 11.03.2024
```
